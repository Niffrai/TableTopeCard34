# Tabletop Simulator — Custom Deck Builder (Rule34 / Xbooru)

Автоматический генератор кастомных колод для **Tabletop Simulator** с поиском по персонажам, тегам, фильтрацией по годам, кастомным столом Tier List и защитой от повторов.

---

## 🚀 Быстрый запуск для пользователей

### Шаг 1. Скачивание программы
* Скачайте готовый архив из раздела **[Releases](https://github.com/Niffrai/TableTopeCard34/releases)** (файл `TableTopCard34_v1.0.0.zip`).
* Распакуйте архив в любую удобную папку на вашем компьютере.

### Шаг 2. Установка зависимостей
* Убедитесь, что у вас установлен **[Python 3.10+](https://www.python.org/downloads/)** (при установке обязательно поставьте галочку *"Add python.exe to PATH"*).
* Запустите файл **`install_dependencies.bat`** (он проверит Python и автоматически установит библиотеку Pillow).
  *(Либо просто сразу запускайте `run.bat` — он сам проверит и установит недостающие библиотеки при первом старте).*

### Шаг 3. Запуск
* Запустите файл **`run.bat`**.
* В браузере автоматически откроется страница: **`http://127.0.0.1:5000`**.

## ✨ Возможности

1. **Кастомный стол Tier List + стилизованный тёмный фон:**
   * При сохранении как игра (`Games → Save & Load`) автоматически генерируется кастомный игровой стол Tier List (2560×1440) с цветными тирами (`S`, `A+`, `A`, `B+`, `B`, `C+`, `C`) и зоной `DECK / DRAW`.
   * **Тёмный стилизованный фон (Skybox):** В игру автоматически подгружается панорамный тёмный фон (2560×1280) в стиле глубокого индиго/неона с манга-силуэтами (без 18+). Это полностью убирает белые засветы и зеркальные блики на карточках, делая их контрастными и чёткими.

2. **Вкладка «📚 Вшитые колоды в TTS» (просмотр и удаление):**
   * В верхней части приложения добавлена отдельная вкладка для просмотра всех установленных колод (как Игр `Save & Load`, так и `Saved Objects`).
   * Отображается превью колоды, количество карт, число листов, дата и имя файла.
   * Можно удалять отдельные колоды нажатием кнопки **«🗑️ Удалить»** или очистить все созданные колоды одной кнопкой.

3. **Постоянная база истории (без повторов между колодами):**
   * Карточки, скачанные в предыдущих сессиях, сохраняются в `history.json`.
   * При следующих генерациях и перезапусках сервера скрипт помнит все ранее созданные карты и выбирает только новые арты из глубины архива сайта.
   * В шапке отображается количество карт в истории, с кнопкой сброса при необходимости.

4. **Папка с индивидуальными фото:**
   * Каждая скачанная фотография сохраняется в высоком качестве в папку `output/photos/` (`photo_001.jpg`, `photo_002.jpg`...).

5. **Колоды любого размера (до 456+ карт):**
   * Автоматическая нарезка на листы сетками 10×7 (например, 456 карт = 6 листов по 70 карт + 1 лист на 36 карт).
   * В игре все листы объединяются в единую колоду.

6. **Экспорт и Импорт колод (передача другу в 1 клик):**
   * Кнопка **«📦 Скачать ZIP-архив для друга»** упаковывает все листы карт, стол Tier List, рубашку и файл инструкции `ИНСТРУКЦИЯ_ДЛЯ_ДРУГА.txt` в единый компактный архив.
   * Друг нажимает **«📥 Импортировать от друга»** и выбирает полученный `.zip`: программа сама распакует файлы в его локальную папку `Saves`, перепривяжет пути к текстурам к его ПК (никаких белых карт!) и создаст готовое сохранение игры.
   * Если у друга нет программы, в архиве лежит подробная текстовая инструкция, как импортировать листы напрямую через внутриигровой инструмент `Objects → Custom Deck`.
