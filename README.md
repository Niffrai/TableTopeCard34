# Tabletop Simulator — Custom Deck Builder (Rule34 / Xbooru)

Автоматический генератор кастомных колод для **Tabletop Simulator** с поиском по персонажам, тегам, годам, кастомным столом Tier List и менеджером колод.

---

## ✨ Основные возможности

* 🎴 **Колоды любого размера:** автоматическая сборка и нарезка листов (до 1024 карт) с идеальной геометрией (сетка 10×7, без искажений и пустых ячеек).
* 🔍 **Умный поиск и фильтрация:** многопоточная загрузка по тегам Booru, расширенный лимит до 12 тегов, авто-фильтрация синонимов и настраиваемые щиты от нежелательного контента.
* 🎨 **Стол Tier List и тёмный Skybox:** автоматическая генерация размеченного стола (тиры S..C) и неонового индиго-фона, убирающего засветы карт.
* 📦 **Экспорт и импорт в 1 клик:** упаковка колоды в `.zip` для друга и автоматический импорт без битых текстур и конфликтов путей.
* 🌐 **Сетевая совместимость:** интеграция с кэшем `Mods/Images` для корректного отображения у всех игроков в мультиплеере.
* 📚 **Управление колодами:** встроенный просмотр, очистка кэша и удаление колод прямо из веб-интерфейса.
* 🧠 **Защита от дубликатов:** история генераций сохраняется в базе, предотвращая повтор артов.

---

## 🚀 Запуск программы

Готовый архив программы всегда доступен в разделе **[Releases](https://github.com/Niffrai/TableTopeCard34/releases)** (файл `TableTopCard34_v1.0.1.zip`).

### Windows 🪟
1. Установите **[Python 3.10+](https://www.python.org/downloads/)** (обязательно отметьте галочку **«Add python.exe to PATH»**).
2. Распакуйте архив и запустите **`run.bat`** (скрипт сам проверит библиотеки, доустановит нужное и откроет браузер).
3. Интерфейс доступен по адресу: `http://127.0.0.1:5000`.

### Linux 🐧
1. Установите Python и модуль venv:
   * **Ubuntu / Debian / Mint:** `sudo apt update && sudo apt install python3 python3-pip python3-venv`
   * **Arch / Manjaro:** `sudo pacman -S python python-pip`
   * **Fedora:** `sudo dnf install python3 python3-pip`
2. Откройте терминал в папке проекта и выполните:
   ```bash
   chmod +x run.sh install_dependencies.sh
   ./run.sh
   ```
3. Скрипт создаст виртуальное окружение, установит зависимости и откроет `http://127.0.0.1:5000`.
