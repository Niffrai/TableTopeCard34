Как загрузить колоду в Tabletop Simulator:

  1. Способ 1 — Как готовую ИГРУ (Рекомендуется): Нажмите кнопку «Сохранить как ИГРУ». В Tabletop Simulator выберите Create → Singleplayer / Multiplayer → Games → Save & Load. Игра откроется с кастомным столом Tier List (S, A+, A, B+, B, C+, C) и тёмным фоном, на котором в специальной зоне уже будет лежать готовая колода.
  2. Способ 2 — Как ОБЪЕКТ: Нажмите кнопку «Сохранить в Saved Objects». На любом столе в игре откройте Objects → Saved Objects и перетащите колоду.

Как передать колоду другу в Tabletop Simulator

Вы можете переслать готовую колоду другу в одном ZIP-архиве. В архиве упакованы все необходимые текстуры стола Tier List, листы карт, рубашка и текстовая инструкция.

Способ 1: У друга тоже есть это приложение (1 клик — Рекомендуется)

  1. После генерации колоды нажмите кнопку «Скачать ZIP-архив для друга».
  2. Отправьте скачанный архив TTS_Deck_Package.zip другу (через Telegram, Discord и т.д.).
  3. Друг открывает веб-приложение и в шапке нажимает кнопку «Импорт архива».
  4. Выбирает полученный ZIP-файл. Приложение автоматически распакует файлы в его папку Tabletop Simulator и свяжет локальные текстуры (белых карт не будет).
  5. Друг заходит в Tabletop Simulator: Create → Games → Save & Load и загружает появившееся сохранение. Стол Tier List и колода готовы к игре.

Способ 2: У друга нет этого приложения (Ручной импорт в игре)

  1. Друг распаковывает присланный архив .zip в любую папку на диске. Внутри лежит файл ИНСТРУКЦИЯ_ДЛЯ_ДРУГА.txt.
  2. В игре Tabletop Simulator нажимает: Objects → Components → Cards → Custom Deck.
  3. В окне настроек колоды указывает:
    • Face (Лицо): выбирает файл deck_sheet_1.png из архива.
    • Back (Рубашка): выбирает card_back.png.
    • Width (Ширина): 10.
    • Height (Высота): 7.
    • Number (Количество карт): 70.
  4. Нажимает Import. Если листов несколько, аналогично импортирует остальные листы, а затем объединяет их клавишей G в одну стопку.
